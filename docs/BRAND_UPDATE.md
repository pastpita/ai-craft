# AI CRAFT — Brand Update

## Positioning

**AI CRAFT** is a living block world where every villager has a mind. Villagers remember, think differently, gather, farm, build, trade, form routines and grow their villages without a script.

One line: **Every villager thinks for itself.**

## Mark: the block brain

A brain silhouette built from cubes in the world's own materials.

- Top faces: grass. Side faces: dirt with a grass fringe on the upper row. Deep faces: plain dirt.
- Two hemispheres split by a fissure; folds (sulci) are cut as one-block grooves, so the dirt walls show through like terraced hills.
- A short stone-and-dirt stem under the back, like the block a grass block sits on.
- Reads as a brain first at 16 px (favicon), at 32 px (top bar) and at hero scale.
- No text inside the mark.

Variants (all generated from one voxel model in `web/js/brain.js` and `tools/brand.js`):

| Use | Form |
|---|---|
| Favicon, top bar | 2D isometric pixel render on transparent background |
| Loading screen | 3D, assembles cube by cube, then breathes |
| Homepage | 3D mark beside the headline, over the live world |
| GitHub | `assets/brand/block-brain.svg` and a 1280×640 banner PNG |

## Name

Wordmark: `AI CRAFT` set in the pixel display face, uppercase, letter-spacing 0.08em. The mark sits left of the wordmark.

## Type

- Display: Pixelify Sans (pixel, game-native).
- Body: Atkinson Hyperlegible (readable at small sizes).
- Data: IBM Plex Mono (scores, clocks, tables).

## UI language

- Panels: stone body, 3 px bevel, plank header strip.
- Slots: recessed squares for items, faces and stats (inventory logic).
- Buttons: grass-topped (primary), plank (secondary), stone (neutral).
- Icons: 8×8 pixel drawings (task, need, skill), never emoji.

## Voice

Clean, confident, game-native, not overhyped.

- Every villager thinks for itself.
- Not scripted NPCs. Autonomous minds.
- AI villagers that remember, build and evolve.
- Watch a block-world society emerge in real time.
